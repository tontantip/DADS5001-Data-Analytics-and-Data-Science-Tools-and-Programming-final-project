## Motivation (แรงบันดาลใจและวิสัยทัศน์)

### 💡 เปลี่ยน "ข้อมูลมหาศาล" ให้เป็น "คำตอบที่เรียบง่าย" ในการลงทุน

ในโลกการลงทุนยุคปัจจุบัน เราไม่ได้ขาดแคลนข้อมูล แต่เรากำลัง**จมอยู่กับกองข้อมูลมหาศาล (Information Overload)**  
ความท้าทายที่แท้จริงคือการ **"สังเคราะห์" (Synthesize)** ข้อมูลเหล่านั้นเพื่อค้นหาเพชรเม็ดงามในตลาดหุ้น

![Information Overload](https://images.unsplash.com/photo-1642655358689-56b944d6f5f6?q=80&w=1170&auto=format&fit=crop&ixlib=rb-4.1.0&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA &ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D)

### 🚀 แรงบันดาลใจ

แรงบันดาลใจของโปรเจกต์นี้ คือความเชื่อที่ว่า  
> **"การลงทุนที่มีคุณภาพ ไม่ควรเป็นเรื่องซับซ้อน"**

โดยการนำเทคโนโลยี **AI (Large Language Model)** ที่มีความเข้าใจบริบททางเศรษฐกิจและการเงิน  
มาผสานกับความแม่นยำของ **Machine Learning (Traditional)**

เราได้สร้าง **"AI Investment Copilot"** ที่จะเปลี่ยนกระบวนการวิเคราะห์หุ้นที่ต้องใช้เวลาหลายชั่วโมง  
ให้กลายเป็นระบบ **Rating 5 ดาว** ที่กลั่นกรองจากศักยภาพทางธุรกิจที่แท้จริง

เพื่อให้นักลงทุนสามารถทำกำไรได้อย่าง **ยั่งยืน มั่นใจ และมีเหตุผลรองรับ** ในทุกการตัดสินใจ

![AI & Future Finance](https://images.unsplash.com/photo-1745674684468-b9fc392fda3f?q=80&w=1170&auto=format&fit=crop&ixlib=rb-4.1.0&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D)

## The Issue (ปัญหาและที่มาของโครงการ)

### ❓ ทำไมการเลือกหุ้น "ผู้ชนะ" ถึงเป็นเรื่องยากสำหรับนักลงทุนส่วนใหญ่?

ในปัจจุบันข้อมูลการลงทุนหาง่าย แต่การเปลี่ยน **ข้อมูลดิบ (Raw Data)** ให้เป็น **กลยุทธ์ที่ทำกำไรได้ (Actionable Insight)** กลับเต็มไปด้วยอุปสรรค  
ทำให้นักลงทุนจำนวนมากจบลงด้วยการ **"เดา"** หรือ **"ซื้อตามกระแส"** ซึ่งขาดความยั่งยืน

![The Complexity of Finding Winners](https://github.com/tontantip/Archive/blob/main/Image_dads5001_project/Gemini_Generated_Image_q62ddnq62ddnq62d.png?raw=true)

**QuantSense** จึงถูกพัฒนาขึ้นด้วย **Web Application (Streamlit)** ที่ทำหน้าที่:
- รวบรวม จัดการ และวิเคราะห์ข้อมูลแทนคุณ
- ใช้ **GenAI** สวมบทบาทผู้เชี่ยวชาญให้คะแนนปัจจัยพื้นฐาน 0-5 ดาว
- ใช้ **Machine Learning** คำนวณความน่าจะเป็นของราคา

เพื่อให้คุณเห็นภาพรวมของ **"โอกาส"** และ **"ความเสี่ยง"** ได้ชัดเจนที่สุดในหน้าเดียว

## Project Objectives (วัตถุประสงค์)

โครงการนี้มีวัตถุประสงค์เพื่อพัฒนา **Investment Decision Support System** ดังนี้

![Project Objectives](https://github.com/tontantip/Archive/blob/main/Image_dads5001_project/Gemini_Generated_Image_y91fzby91fzby91f.png?raw=true)

1. **พัฒนาแพลตฟอร์มการแสดงผลข้อมูลทางการเงินเชิงโต้ตอบ (Interactive Financial Visualization Platform)**
   - สร้าง Web App ด้วย **Streamlit** ที่เสถียรและใช้งานง่าย
   - Dashboard แบบ Single View ลดเวลาการตรวจสอบข้อมูล

2. **ประยุกต์ใช้ AI ในการวิเคราะห์ปัจจัยพื้นฐานเชิงคุณภาพ**
   - ใช้ **LLM** เป็น Financial Analyst Persona
   - แปลงผลวิเคราะห์ซับซ้อนเป็น **ระบบคะแนน 0-5 ดาว**

3. **สร้างแบบจำลองการทำนายราคาด้วย Machine Learning**
   - ฝึกโมเดลด้วยข้อมูลย้อนหลัง 10 ปี
   - พยากรณ์แนวโน้มราคาจาก Price Action + Volume

## Methodology (วิธีการ)

### 🤖 AI System (Generative AI)
ใช้ Large Language Model เป็นผู้เชี่ยวชาญวิเคราะห์ปัจจัยพื้นฐาน แล้วให้คะแนน 0-5 ดาว

![AI Methodology](https://github.com/tontantip/Archive/blob/main/Image_dads5001_project/Gemini_Generated_Image_fbw36jfbw36jfbw3.png?raw=true)

### 🧠 Machine Learning
ใช้ Traditional ML (เช่น Random Forest, XGBoost ฯลฯ) ฝึกด้วยข้อมูลราคาและปริมาณการซื้อขาย 10 ปี เพื่อพยากรณ์แนวโน้มราคา
